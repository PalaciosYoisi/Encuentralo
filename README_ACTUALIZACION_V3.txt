ENCUÉNTRALO V3 - COINCIDENCIAS REFORZADAS

1. Con Apache y MySQL encendidos, entra a phpMyAdmin.
2. Selecciona encuentralo_db > Importar.
3. Importa actualizar_encuentralo_v3.sql UNA SOLA VEZ.
4. Reemplaza los archivos del sitio por esta versión, conservando la carpeta uploads si deseas mantener fotos anteriores.
5. Ctrl+F5 en el navegador.
6. IMPORTANTE: los reportes creados antes de V3 no tienen image_hash. Para probar al máximo, crea reportes nuevos.
7. Una coincidencia de recuperación requiere un reporte PERDIDO y otro ENCONTRADO. Los reportes del mismo tipo aparecen aparte como 'Reportes parecidos en la comunidad'.
