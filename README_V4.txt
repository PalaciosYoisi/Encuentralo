ENCUÉNTRALO V4 - COINCIDENCIA VISUAL ESTRICTA

1. No requiere cambios nuevos en la base de datos si ya instalaste V3.
2. Reemplaza los archivos PHP/assets por esta versión y conserva tu carpeta uploads.
3. Presiona Ctrl+F5 en el navegador.
4. Las coincidencias principales se muestran SOLO entre PERDIDO y ENCONTRADO.
5. Los reportes del mismo tipo solo aparecen aparte como reportes visualmente parecidos.
6. Color, lugar, fecha o categoría NO pueden crear una coincidencia si las imágenes no pasan primero el filtro visual.
7. Una fotografía idéntica se detecta como coincidencia casi total.
8. Se añadió favicon con el logo de Encuéntralo.
