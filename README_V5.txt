ENCUÉNTRALO V5 — ESTADO RESUELTO

Cambio principal:
- PERDIDO y ENCONTRADO siguen siendo tipos de reporte.
- Cuando el autor cierra el caso, el tipo NO cambia. El estado pasa de open a resolved.
- Un reporte PERDIDO resuelto sigue siendo un reporte de objeto perdido, pero aparece con la etiqueta RESUELTO.
- Un reporte ENCONTRADO resuelto sigue siendo un reporte de objeto encontrado, pero aparece con la etiqueta RESUELTO.
- El contador Casos resueltos suma todos los reportes con status=resolved.
- Solo el autor (o administración) puede modificar el estado.

No requiere cambios en la base de datos si ya instalaste V4.
Conserva tu carpeta uploads al actualizar.
